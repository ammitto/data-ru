= Ammitto Russia entry-ban data

This repository maintains Russian Ministry of Foreign Affairs entry-ban
statements as YAML for Ammitto. The statements bar named foreign nationals
from entering Russia; contributors record one statement and its source URL
per file in `sources/announcements/`, with reference copies in
`reference-docs/`.

== Source

* Publisher: Ministry of Foreign Affairs of the Russian Federation
* Website: https://mid.ru/

The ministry announces these measures as statements on its website, not as a
downloadable list. Each file here records the URL of the statement it was
transcribed from (`announcement.url`).

== Contents

The data is in `sources/announcements/`, one file per statement, named after
a date, usually its publication date (`sources/announcements/20250820.yml`), with a suffix
when there are several on one day (`20220413-1.yml`).

`sources/legal-instruments/` holds the law the statements cite, in Russian and
English; `sources/supporting/` holds identifiers for lists, publishing bodies
and document types; `schemas/` holds the schemas. `reference-docs/` holds
copies of the statements and of the ministry's full lists for some countries,
and of the law. `processed/` is empty.

Each statement file:

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `announcement.title` | map | Title in Russian (`ru`) and English (`en`)
| `announcement.url` | string | URL of the statement on mid.ru
| `announcement.publish_date`, `publish_time` | string | Publication date (`YYYY-MM-DD`) and time
| `announcement.authority`, `publisher`, `signatory` | string | Issuing body, as an identifier from `sources/supporting/organizations.yml`
| `announcement.type` | string | Document type
| `announcement.document_id` | string | The ministry's document number, as transcribed
| `announcement.lang` | string | Language of the original, `ru`
| `announcement.content` | map | Full text in Russian and English
| `sanction_details.instruments` | list | Laws cited, by `id`
| `sanction_details.entities` | list | The people named, described below
|===

Each entry in `sanction_details.entities`:

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `name` | map | Name in Russian and English
| `type` | string | `individual`
| `nationality` | string | Country code, such as `US` or `GB`
| `title` | map | Position as stated, in Russian and English
| `effective_date` | string | Date the ban applies from
| `sanction_list` | string | The list, as named in the statement
| `reason` | list | Reason given, in Russian and English
| `measures` | list | The measure, in Russian and English, with a `type`, which is itself a list of codes, such as `[entry_ban]`
|===

== Using the data

Clone or download this repository and run either example from its root
directory. The Python example requires PyYAML
(`python3 -m pip install PyYAML`).

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("sources/announcements/*.yml").sort.each do |path|
  doc = YAML.safe_load_file(path, aliases: true)
  date = doc["announcement"]["publish_date"]
  doc["sanction_details"]["entities"].each do |entity|
    puts [date, entity["nationality"], entity["name"]["en"].split.join(" ")].join("\t")
  end
end
----

Python:

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("sources/announcements/*.yml")):
    with open(path, encoding="utf-8") as f:
        doc = yaml.safe_load(f)
    date = doc["announcement"]["publish_date"]
    for entity in doc["sanction_details"]["entities"]:
        print(date, entity["nationality"], " ".join(entity["name"]["en"].split()), sep="\t")
----

== Updates

This repository is maintained by hand: a statement is copied as Markdown into
`reference-docs/announcements/` and converted with
`scripts/parse_announcements.rb`; `scripts/validate.rb` checks the result
against the schemas.

== Maintaining the data

Use Ruby and Bundler to install the link:Gemfile[Gemfile] dependencies. From
the repository root, convert a saved statement into `sources/announcements/`
and validate the source files:

[source,shell]
----
bundle install
bundle exec ruby scripts/parse_announcements.rb --output-dir sources/announcements reference-docs/announcements/YYYYMMDD.md --validate
bundle exec ruby scripts/validate.rb
----

Replace `YYYYMMDD.md` with the saved statement's filename. The explicit
input path selects the reference copy; `--output-dir` places the generated
YAML in the source corpus. `--validate` checks that output, and the final
command checks the source files against link:schemas/[schemas/]. Parser and
validator changes belong in this repository's link:lib/ammitto-data-ru/[lib/]
and link:scripts/[scripts/].
