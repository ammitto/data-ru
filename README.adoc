= Ammitto Russia Sanctions Data Repository

== Purpose

This repository stores curated sanctions data from the
Russian Federation government sanctions announcements.

The data is maintained by the Ammitto project and used by the `ammitto` Ruby
gem for querying international sanctions information.

== Legal Basis

Russia maintains sanctions and restrictive measures lists through:

* **Стоп-лист (Stop-list)** - Ministry of Foreign Affairs (MID)
* **Central Bank Sanctions** - Central Bank of Russia (CBR)
* **Government Decrees** - Постановления

These are implemented through federal laws and government decrees
authorizing reciprocal sanctions against foreign persons and entities.

== Data Source

Russia maintains sanctions lists through:

.Stop-list (Стоп-лист)
* **Authority**: Ministry of Foreign Affairs (МИД России)
* **URL**: https://mid.ru
* **Effects**: Entry bans on foreign persons

.Central Bank Sanctions
* **Authority**: Central Bank of Russia (ЦБ РФ)
* **Effects**: Financial sanctions

.Government Decrees
* **Authority**: Government of Russia
* **Effects**: Various economic restrictions

== Special Considerations

* **Format**: HTML announcements (not structured XML/JSON)
* **Language**: Russian with English transliterations
* **Parsing**: Requires HTML extraction from official announcements
* **Encoding**: UTF-8 with Cyrillic characters

== Directory Descriptions

processed/:: Holds only `.gitkeep`. The data is the YAML under `sources/`.

reference-docs/:: Contains reference documentation and translations.

== Updating Data

The YAML under `sources/` is maintained by hand in this repository, with
the help of the scripts in `scripts/`:

[source,shell]
----
# Fetch a legal instrument from kremlin.ru and convert it to YAML
bundle exec ruby scripts/fetch_legal_instrument.rb <kremlin_print_url>

# Validate the YAML against the schemas
ruby scripts/validate.rb
----

== Source Data Format

`processed/` holds only `.gitkeep`. The data is the YAML under `sources/`,
maintained by hand. Each file under `sources/announcements/` holds an
`announcement` block and a `sanction_details` block, whose `entities` list
carries one entry per sanctioned person
(schema: `schemas/announcement-schema.yml`):

[source,yaml]
----
sanction_details:
  instruments:
  - id: ru/federal-law-114
  entities:
  - name:
      ru: Мэри Саймон
      en: Mary Jeannie May Simon
    type: individual
    nationality: CA
    title:
      ru: без должности
      en: no title
    effective_date: '2023-04-12'
    sanction_list: черного списка
    reason:
    - ru: За участие в антироссийской деятельности канадского правительства.
      en: For participation in anti-Russian activities of the Canadian government.
    measures:
    - type:
      - entry_ban
      ru: Запрещен въезд в Российскую Федерацию.
      en: Entry into the Russian Federation is prohibited.
----

=== Field Definitions

[cols="1,4"]
|===
| Field | Description

| `name`
| Name keyed by language (`ru`, `en`)

| `type`
| Entity type; every current entry is `individual`

| `nationality`
| Two-letter country code, e.g. `CA`

| `title`
| Position or description, keyed by language

| `effective_date`
| Date the entry ban takes effect

| `sanction_list`
| The list named in the announcement, as written there

| `reason`
| Array of reasons, each keyed by language

| `measures`
| Array of measures: `type` codes plus the measure text keyed by language
|===

`sources/legal-instruments/` holds the legal basis (Federal Law No. 114-FZ)
and `sources/supporting/` the organizations, document types and sanction
lists the announcements refer to.

== Harmonized Data Format

After harmonization, entities are transformed into JSON-LD format:

=== Entity (JSON-LD)
[source,json]
----
{
  "@context": "https://www.ammitto.org/schema/v1/context.jsonld",
  "@id": "https://www.ammitto.org/entity/ru/001",
  "@type": "PersonEntity",
  "names": [
    {
      "@type": "NameVariant",
      "fullName": "PRIMARY NAME (Кириллица)",
      "script": "Cyrl",
      "isPrimary": true
    },
    {
      "@type": "NameVariant",
      "fullName": "PRIMARY NAME (Latin)",
      "script": "Latn",
      "isPrimary": false
    }
  ],
  "sanctionEntries": [
    {
      "@id": "https://www.ammitto.org/entry/ru/001",
      "@type": "SanctionEntry",
      "authority": {
        "@id": "https://www.ammitto.org/authority/ru",
        "name": "Russia"
      },
      "regime": {
        "@type": "SanctionRegime",
        "code": "STOP_LIST",
        "name": "Stop List"
      },
      "effects": [
        {
          "@type": "SanctionEffect",
          "effectType": "travel_ban",
          "scope": "full"
        }
      ],
      "status": "active"
    }
  ]
}
----

== Entity Types

The Russian sanctions lists contain the following entity types:

Person:: Individual persons subject to sanctions
Organization:: Legal entities, companies, and organizations
